# BPU v18 — двухканальный предиктор ветвлений для SCR1

> Рабочий снапшот линейки разработки: v18 → v19 → v21 → v23 → релиз `bpu_scr1_release_v1.0.0` (2026-11-13). Микроархитектура — та же, что в релизе; релиз довёл линейку до полной приёмки.

## Что это

Предиктор ветвлений для ядра SYNTACORE SCR1 (RV32IMC + RVC), встроенный в `scr1_pipe_ifu`. Предсказание выполняется в момент ответа IMEM: очередь выборки направляется (steer) на предсказанный target, при миспредикте EXU перенаправляет поток и отбрасывает wrong-path слова. Обучение — только на коммите. Интеграция через хуки в `scr1_pipe_top` / `scr1_pipe_ifu` / `scr1_pipe_exu`; остальные файлы соответствуют оригинальному SCR1.

Ключевые файлы: `rtl/pipeline/scr1_pipe_bpu.sv`, `rtl/pipeline/scr1_pipe_ifu.sv`, `rtl/pipeline/scr1_pipe_top.sv`, `rtl/pipeline/scr1_pipe_exu.sv`, `rtl/includes/scr1_arch_description.svh`.

## Устройства

Структура устройств линейки v18 → 1.0.0 (параметры приведены по релизной конфигурации):

- **Два канала предсказания**: ch1 — нижний полуворд, straddled RVI или первая инструкция после redirect; ch2 — полная RVC-инструкция в верхнем полуворде. Оба канала комбинационные, срабатывают в такт ответу IMEM.
- **BHT**: 1024 записи × {valid, tag = PC[13:12], 2-bit saturating counter}, индекс PC[11:2]; read-during-write bypass; аллокация на промахе: taken → WT(10), not-taken → WN(01); предсказание по ctr[1]; вектор valid чистится только на reset — без reset-loop по всей таблице.
- **RAS**: 8 записей, push на коммите call (JAL/JALR/C.JAL/C.JALR с rd=ra), pop на коммите ret, peek в момент предсказания, top-overwrite при переполнении.
- **Steer выборки**: по предсказанию следующий запрос IMEM уходит на целевое слово, слот очереди помечается (`q_bpu_str`) — EXU знает, что инструкция предсказана и с каким target.
- **Zero-bubble на верных taken**: согласие предсказания с разрешением ветвления в EXU (`flush_skip`) — taken-переход без пузырей; миспредикт — redirect (`pc_new_req`) + discard wrong-path слов очереди.
- **Не-спекулятивное обучение**: BHT/RAS обновляются только на коммите (`exu2pipe_instret`) — таблицы не нужно откатывать на миспредиктах.
- **fence.i** (`bpu_flush_i`): сброс FTB и RAS; BHT сохраняется.
- **FTB** (32 записи, redirect на запросе): компилируется под `SCR1_BPU_FTB_EN`, по умолчанию выключен.
